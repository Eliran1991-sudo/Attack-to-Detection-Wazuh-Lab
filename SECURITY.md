# Security Policy

## Scope

This repository documents an authorized local SOC laboratory. It does not contain production systems, customer data, malware, exploitation instructions, or credentials.

## Reporting sensitive information

Do not open a public issue containing credentials, tokens, private keys, personal information, production addresses, or unsanitized logs.

If sensitive information is found, report it privately through GitHub's security reporting feature when available, or contact the repository owner through the contact method listed on the GitHub profile.

Include the affected file and a concise description, but do not reproduce the sensitive value in the report unless a private channel is confirmed.

## Evidence handling

- Use only data collected from systems you own or are authorized to test.
- Sanitize screenshots, command output, logs, usernames, addresses, and identifiers before publication.
- Do not commit enrollment keys, passwords, access tokens, private keys, virtual disks, packet captures containing private traffic, or raw production logs.
- Record timestamps with their timezone.
- Separate verified evidence from assumptions and planned work.

## Safe use

The content is provided for defensive learning in an isolated laboratory. Do not direct reconnaissance, detection simulations, or administrative scripts at public or third-party systems without explicit authorization.
